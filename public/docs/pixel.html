Brands

Pixel and Conversions API

Ask a question

Count sign-ups and sales that came from your ads, from the browser or from your server, without cookies and without knowing who anyone is.

#How it works

A click on your ad adds ?isoteh_ref=… to your link. The reference names the ad and the day, the same for everyone who clicked that ad that day, so it can never point to one person. You send it back with what happened, from the browser or from your server, and we count it against the ad.

#The browser tag

  1. Add the tag to every page

    HTML
    <script async src="https://isoteh.amaete.com/s/isoteh-events.js"></script>

  2. Send events where they happen

    JavaScript
    isoteh('sign_up');
isoteh('purchase', { value: 24.00, currency: 'USD' });

  3. Check it

    Click your own ad, then do the action. The event shows in Events within a minute.

The tag keeps the reference only for that browser tab (session storage), sets no cookies, and sends nothing at all for visitors who did not arrive from an ad. A visit from an ad sends a page_view by itself.

#Conversions API (from your server)

Send events from your backend when the browser can't be trusted to: a payment confirmed by your processor, a renewal, a sale in a shop. Keep the reference from the landing page with the order.

curl https://isoteh.amaete.com/v1/events \
  -H 'Authorization: Bearer isk_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"event":"purchase","ref":"REF_FROM_THE_LINK","value":2400,"currency":"USD"}'
await fetch('https://isoteh.amaete.com/v1/events', {
  method: 'POST',
  headers: { authorization: 'Bearer ' + process.env.ISOTEH_KEY, 'content-type': 'application/json' },
  body: JSON.stringify({ event: 'purchase', ref: order.isotehRef, value: 2400, currency: 'USD' }),
});
import os, requests

requests.post('https://isoteh.amaete.com/v1/events',
  headers={'Authorization': f"Bearer {os.environ['ISOTEH_KEY']}"},
  json={'event': 'purchase', 'ref': order.isoteh_ref, 'value': 2400, 'currency': 'USD'})

#Request body

FieldTypeNotes
eventtextLower case, like purchase or sign_up, 2 to 32 characters
reftextThe isoteh_ref from the landing page. Valid for 31 days.
valuewhole numberIn minor units: 2400 is $24.00. Optional.
currencytextISO code, like USD. Optional.
countwhole numberHow many, when you send several at once. Optional.

#Response

JSON
{ "ok": true, "matched": true }

matched is false when the reference is missing, expired or belongs to another account. The event is still kept, without an ad.

#Keys

Make an API key under Settings. Keys start with isk_. Keep them on your server, never in a browser or an app.

The browser tag needs no key. Only the Conversions API does.

#Troubleshoot

ProblemCause and fix
No events showVisits did not come from an ad, so there is no reference. Click your own ad to test.
Events show without an adThe reference was lost on a redirect. Keep the query string, or save the reference at landing.
401 Sign in firstThe key is wrong or was deleted. Make a new one.
415 Send JSONSet Content-Type: application/json.
