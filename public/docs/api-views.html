API reference

Views and clicks

Ask a question

Each ad carries two links. Call the view link once it was seen, and send taps through the click link.

#View

HTTP
POST https://isoteh.amaete.com/t/v?k=TOKEN      (or GET, which returns a 1×1 image)

Call it once, after the ad has passed the view rule. Repeats of the same token are ignored. Answers 204.

#Click

HTTP
GET https://isoteh.amaete.com/c?k=TOKEN   →   302 to the brand's page, with utm_source, utm_medium and isoteh_ref

Open it in a new tab or the system browser. Robots are ignored and each reader's click counts once.
