Ask a question

Turn any surface in your world into a billboard. A view counts only when the player can really read it.

#Three.js

JavaScript
import { AdBoard } from 'https://isoteh.amaete.com/s/isoteh-three.mjs';

const board = new AdBoard(THREE, { server: 'https://isoteh.amaete.com', slot: 'sl_your_slot', width: 8, height: 4 });
board.mesh.position.set(0, 3, -20);
scene.add(board.mesh);

function frame(dt) {
  board.update(camera, renderer, dt, { occluders: [buildings] });
  renderer.render(scene, camera);
}

// on tap or click
if (board.hit(raycaster)) board.open();

Pass your own THREE, so the SDK carries no copy of it. The board shows the ad with a small Sponsored strip, an Advertise here card when the space is free, or a plain panel.

#When a view counts

RuleValue
Part of the board on screen and not hiddenAt least half
Share of the screen it coversAt least 1.5%
Angle from straight onAt most 55°
Time in a row1 second

These follow the common rules for in-game ads, so brands can trust the numbers. Nothing about the player is sent.

#Any engine

Unity, Godot or your own engine: fetch the ad, draw its image on a surface, call its view link once the player has seen it for a second, and open its click link on tap.

HTTP
GET https://isoteh.amaete.com/v1/ad?slot=sl_your_slot&kw=racing,cars

{
  "ad": { "kind": "image", "sponsor": "Juniper Coffee", "image": "https://isoteh.amaete.com/cr/….png", "width": 1200, "height": 600 },
  "label": "Sponsored",
  "view": "https://isoteh.amaete.com/t/v?k=…",
  "click": "https://isoteh.amaete.com/c?k=…"
}

The GameAd class in isoteh-game.mjs holds the same rules without Three.js, if you want to port them. See the game SDK.
