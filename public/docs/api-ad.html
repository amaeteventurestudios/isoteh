API reference

Get an ad

Ask a question

GET /v1/ad returns the ad for a space right now, an Advertise here offer, or nothing.

Request
GET https://isoteh.amaete.com/v1/ad?slot=sl_your_slot&kw=coffee,austin

#Query

NameRequiredMeaning
slotYesThe space id
kwNoTopic words, comma separated
ctxNoprivate, dm or direct returns no ad
countryNoTwo-letter country code, when you know it from context
