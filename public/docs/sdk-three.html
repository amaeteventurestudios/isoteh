Reference for AdBoard: a billboard mesh that loads, draws and counts its own ad.

Constructor
new AdBoard(THREE, { server, slot, width = 4, height = 2, keywords = '', px = 512 })

#Options

OptionDefaultMeaning
width, height4, 2Size in scene units
keywords''Topic words, like racing, cars
px512Width of the drawn texture in pixels

#Methods

MethodWhat it does
meshThe mesh to add to your scene
update(camera, renderer, dt, { occluders })Call every frame; measures what the player sees and sends the view once
hit(raycaster)True when a ray hits the board
open()Opens the brand's page
reload()Asks for a new ad, for example on a new level
