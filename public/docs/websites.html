Websites and blogs

Ask a question

One div and one script line. The space is kept free while the ad loads, so the page never jumps, and nothing about your readers is sent anywhere.

#Add the code

HTML
<div data-isoteh="sl_your_slot"></div>
<script async src="https://isoteh.amaete.com/s/isoteh.js"></script>

Load the script once per page, even with several spaces. Each data-isoteh div becomes one ad.

#Keep the layout still

Give the box its size so nothing moves when the ad arrives. If you set a size on the space, the dashboard's code already includes it.

HTML
<div data-isoteh="sl_your_slot" style="max-width:300px;aspect-ratio:300/250"></div>

#Tell us what the page is about

Topic words help pick a fitting ad. They describe the page, never the reader.

HTML
<div data-isoteh="sl_your_slot" data-keywords="coffee, austin, recipes"></div>

If the page has a <meta name="keywords"> tag, its words are used too.

#What the script does

  • Loads the ad only when the space is near the screen.
  • Draws it inside a shadow root, so your styles and the ad's never mix.
  • Labels it Sponsored and links out with rel="sponsored".
  • Counts a view once, when half the ad has been on screen for a second while the tab is visible.
  • Sets no cookies and uses no storage.

#WordPress

  1. Install the plugin

    Download isoteh.php and upload it under Plugins, Add New, Upload. It is a 40-line shortcode and nothing else.

  2. Set the server

    Under Settings, Isoteh, set the server address to https://isoteh.amaete.com.

  3. Place the shortcode

    Put it in any post, page or widget.

    Shortcode
    [isoteh slot="sl_your_slot"]
No plugin? Paste the website code into a Custom HTML block instead. It works the same.

#Ghost

Add an HTML card where the ad goes and paste the website code. To show it on every post, put the script line in Settings, Code injection, Site footer, and the div in your theme where the ad belongs.

#Other site builders

Any builder that allows an HTML or embed block works: Webflow, Squarespace, Framer, Wix and plain HTML. Paste the website code into it.
