Start here

Isoteh sells the ad space you already have. You make an account, add a space (a spot on a page, a block in a newsletter, a board in a game), set its price, and paste one small piece of code where the ad should appear. Brands book it and pay up front. You approve each ad before it runs, and you are paid after it has run.

  1. Make an account. Listing is free.
  2. In the dashboard, add a space and choose what it is: banner, native card, email, game board or creator post.
  3. Copy the code the dashboard gives you. It carries the space's own id, which looks like sl_ followed by letters.
  4. Paste it where the ad should go, using the guide below for your kind of place.

Every example on this page uses sl_your_slot. Swap in your own space id.

Any website

Paste this where the ad should appear. The space is kept free while the ad loads, so the page never jumps.

<div data-isoteh="sl_your_slot"></div>
<script async src="https://isoteh.amaete.com/s/isoteh.js"></script>

Tell the server what the page is about, so it can choose a fitting ad without knowing anything about the reader:

<div data-isoteh="sl_your_slot" data-keywords="coffee, austin, recipes"></div>

WordPress

Install the small Isoteh plugin from https://isoteh.amaete.com/wordpress/isoteh.php, set the server address once under Settings, then put the shortcode in any post, page or widget. You can also paste the website code into a Custom HTML block.

[isoteh slot="sl_your_slot"]

Ghost

Add an HTML card where the ad goes and paste the website code. To show it on every post, put the script line in Settings, Code injection, Site footer, and the box in your theme.

Newsletters

For Ghost, Beehiiv, Kit, Mailchimp and Brevo, paste this into an HTML block in the email. Replace ISSUE with a new name for every send; the date works well. Everyone who gets one issue sees the same ad.

<table role="presentation" width="100%" style="max-width:600px;margin:16px auto">
  <tr><td style="font:12px sans-serif;color:#777;padding-bottom:4px">Sponsored</td></tr>
  <tr><td><a href="https://isoteh.amaete.com/e/sl_your_slot/c?i=ISSUE"><img src="https://isoteh.amaete.com/e/sl_your_slot.png?i=ISSUE" width="600" alt="Sponsored" style="display:block;width:100%;height:auto;border:0"></a></td></tr>
</table>

Opens are counted, but mail apps load images ahead of time, so treat opens as an estimate. Clicks are exact.

Substack does not run outside code, so open the ready-made block for your issue, add its image to the post, link the image to the link it gives you, and write Sponsored above it:

https://isoteh.amaete.com/e/sl_your_slot/kit?i=ISSUE

Apps and chat

Ask for a card and draw it in your own style, always with the word Sponsored. Cards only come back for public channels and feeds. Send ctx=private from a private chat and you get nothing.

import { getNativeAd } from 'https://isoteh.amaete.com/s/isoteh-native.mjs';

const card = await getNativeAd({ server: 'https://isoteh.amaete.com', slot: 'sl_your_slot', keywords: 'channel topic words' });
if (card) {
  show(card);
  card.seen();   // once it has been on screen for a second
}
// on tap: card.open()

Games

Turn any surface in a Three.js game into a billboard. A view counts only when the board is on screen, big enough, facing the camera and not hidden, for a full second.

import { AdBoard } from 'https://isoteh.amaete.com/s/isoteh-three.mjs';

const board = new AdBoard(THREE, { server: 'https://isoteh.amaete.com', slot: 'sl_your_slot', width: 8, height: 4 });
scene.add(board.mesh);

// every frame:
board.update(camera, renderer, dt, { occluders: [buildings] });

// when the player taps the board:
board.open();

Unity, Godot or your own engine: fetch the ad as JSON, draw its image on a surface, call its view link once the player has seen it for a second, and open its click link on tap.

GET https://isoteh.amaete.com/v1/ad?slot=sl_your_slot&kw=racing,cars

{ "ad": { "image", "width", "height", "sponsor" }, "label": "Sponsored", "view", "click" }

Creators

Share your booking page in your bio or media kit. Brands book and pay up front, you get a tracked link for each post, and you are paid once the post is up.

https://isoteh.amaete.com/book/sl_your_slot

Counting sales

For brands. Put the events tag on every page of your site, then call it where something happens. It sets no cookies, and it sends nothing at all for visitors who did not arrive from an Isoteh ad.

<script async src="https://isoteh.amaete.com/s/isoteh-events.js"></script>

isoteh('purchase', { value: 24.00, currency: 'USD' });
isoteh('sign_up');

A click on an ad adds ?isoteh_ref= to your link. The reference names the ad and the day, the same for everyone who clicked that ad that day, so it can never point to one person.

From your server, send the same events with an API key from the dashboard. The value is in minor units, so 2400 is $24.00.

curl https://isoteh.amaete.com/v1/events \
  -H 'Authorization: Bearer isk_your_key' \
  -H 'Content-Type: application/json' \
  -d '{"event":"purchase","ref":"REF_FROM_THE_LINK","value":2400,"currency":"USD"}'

Ad rules

  • Ads are an image or plain text. No HTML and no scripts, ever.
  • Every ad carries the label Sponsored.
  • No ads in private chats.
  • Readers are never tracked: no cookies, no stored IP addresses, no ids. Ads are chosen by the page's topic and the reader's country only.
  • Owners approve every ad before it runs, and can say no.
